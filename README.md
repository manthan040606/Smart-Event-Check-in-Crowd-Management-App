# 📱 QRifyME - Advanced Event Management Platform

![QRifyME Header](https://raw.githubusercontent.com/manthan040606/Smart-Event-Check-in-Crowd-Management-App/main/assets/banner.png)

> **The ultimate peer-to-peer event management solution.** Designed for high-speed check-ins, real-time crowd dynamics, and a premium administrative experience.

---

## ✨ Features

### 🏢 For Hosts (Admins)
- **Live Intelligence Dashboard**: Real-time stats on capacity, attendance velocity, and remaining spots.
- **Smart Crowd Gauge**: Visual safety indicator powered by live check-in data.
- **High-Speed Scanner**: Native hardware-accelerated QR scanning with instant feedback.
- **Advanced Logs**: Searchable, filterable audit trails for every participant.
- **Quick-Edit Hub**: Update event details on-the-fly without session resets.

### 🎟️ For Attendees
- **Premium Entry Pass**: A sleek, digital-wallet style pass with a unique QR identity.
- **Live Event Updates**: View event details, timing, and hall locations in real-time.
- **Participation Mode**: Integrated scanner for interactive event engagement.

---

## 🎨 Design Philosophy
QRifyME is built with a **Premium Glassmorphic Design System**:
- **Navy & Emerald Palette**: High-contrast professional themes for maximum readability.
- **Dynamic Micro-Animations**: Smooth HERO transitions and haptic feedback on every interaction.
- **Role-Adaptive UI**: The entire app personality shifts based on whether you are managing or participating.

---

## 🛠️ Tech Stack
- **Frontend**: Flutter (3.32.0 stable)
- **State Management**: Riverpod (Reactive Architecture)
- **Database**: Hive (Ultra-fast local persistence)
- **Scanning Engine**: Mobile Scanner (Hardware Accelerated)
- **Visualization**: FL Chart (Responsive Vector Graphics)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable)
- Dart SDK
- Android Studio / VS Code

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/manthan040606/Smart-Event-Check-in-Crowd-Management-App.git
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the application**
   ```bash
   flutter run
   ```
